# 1초 챌린지

정확히 **1.000초**에 맞춰 멈추는 아이폰용 미니 웹 게임입니다.

## 아이폰에서 하는 법

1. Safari로 이 저장소의 **GitHub Pages URL**을 엽니다.
2. **시작**을 탭한 뒤, 감각으로 1초가 되었다고 느끼면 다시 탭합니다.
3. 경과 시간(소수점 3자리), 오차(ms), 등급, 최고 기록을 확인합니다.
4. (선택) 공유 → **홈 화면에 추가**로 앱처럼 바로가기를 만들 수 있습니다.

## 등급

| 오차 | 등급 |
|------|------|
| ≤ 10 ms | 완벽 |
| ≤ 50 ms | 거의 |
| ≤ 150 ms | 아쉬움 |
| 그 이상 | 다시! |

## 기술

- 바닐라 HTML / CSS / JS (빌드 없음)
- `localStorage`에 최고 기록(절대 오차 ms) 저장
- 지원 기기에서 `navigator.vibrate` 햅틱
- safe-area inset · 큰 터치 영역 · 모바일 퍼스트

## 로컬에서 열기

`index.html`을 브라우저로 열거나, 폴더에서 간단한 정적 서버를 켜면 됩니다.

```bash
python3 -m http.server 8080
```
